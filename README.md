# Minimal Zo Brain

Minimal Zo Brain is a specification-first setup prompt for Zo Computer.

Start here:

https://minimal-zo-brain-site.vercel.app

Full spec gist:

https://gist.github.com/Jeff-Kazzee/f5409e0f20b0a7c71560d2353a9df02a

## What This Repo Is

This repo is intentionally tiny. The important file is:

```txt
spec.md
```

`spec.md` is the prompt Zo reads to interview the user and create a personal second brain around their real life, work, projects, relationships, sources, tasks, decisions, and desired depth.

It is not a prefilled template. It does not contain a starter `brain/` folder. Zo creates that only after talking with the user and getting approval.

## How To Use It

1. Open `spec.md`.
2. Give it to Zo Computer.
3. Ask Zo: `Read spec.md and help me set up my Minimal Zo Brain.`
4. Pick a depth: Starter, Beginner, Intermediate, or Pro.
5. Answer Zo's five setup questions.
6. Review Zo's proposed folder and file plan.
7. Approve the plan only when it matches what you actually want.

## Depths

Starter is a tiny first brain.

Beginner adds simple organization for a few areas.

Intermediate separates context across projects, businesses, relationships, responsibilities, or other life areas.

Pro adds graph-style structure: entities, relationships, provenance, conflicts, and checks.

The website explains the levels in plain language:

https://minimal-zo-brain-site.vercel.app/depths/
